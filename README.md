# Cô Bé Phim Kodi Repository

Kho cài đặt và tự cập nhật cho `plugin.video.cobephim`.

## Cài đặt

1. Tải `repository.cobephim/repository.cobephim-1.0.0.zip`.
2. Trong Kodi chọn **Cài đặt từ file ZIP**.
3. Mở **Cài đặt từ kho lưu trữ → Cô Bé Phim Repository**.
4. Cài plugin **Cô Bé Phim** và bật tự động cập nhật.

## Đổi domain/API

Sửa trực tiếp `config.json` trên nhánh `main`. Không cần đóng gói lại plugin nếu chỉ đổi tên miền, API hoặc host embed.
