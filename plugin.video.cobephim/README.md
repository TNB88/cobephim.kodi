# Cô Bé Phim cho Kodi

Plugin Kodi native: phim hot, phim bộ, phim lẻ, bộ sưu tập, tìm kiếm, chọn server và phát HLS.

Cấu hình domain/API/CDN được tải từ:

`https://raw.githubusercontent.com/TNB88/cobephim.kodi/main/config.json`

Khi trang đổi tên miền, chỉ sửa `config.json` trên GitHub. Plugin lưu cấu hình tốt gần nhất trong profile để vẫn mở được khi GitHub tạm lỗi.
